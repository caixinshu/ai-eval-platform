# 密码管理

## 修改密码

修改密码步骤：
1. 进入「设置」
2. 选择「账户安全」
3. 点击「修改密码」
4. 验证原密码
5. 设置新密码并确认

## 忘记密码

若忘记密码，可通过以下方式重置：
1. 在登录页点击「忘记密码」
2. 输入注册手机号
3. 获取并输入短信验证码
4. 设置新密码

## 密码要求

密码需满足以下要求：
- 长度 8-20 位
- 包含字母和数字
- 建议包含特殊符号
- 不要使用生日、手机号等易被猜到的密码

## 手机号换绑

更换绑定手机号：
1. 进入「设置」-「账户安全」
2. 选择「更换手机号」
3. 验证原手机号
4. 输入新手机号并验证

若原手机号已无法接收验证码，需联系客服人工处理，需提供身份验证信息。
