# X1 Pro 手机参数

## 与 X1 的区别

X1 Pro 是 X1 的升级版本，主要区别如下：

| 参数 | X1 | X1 Pro |
|------|-----|--------|
| 处理器 | 骁龙 7 Gen 3 | 骁龙 8 Gen 2 |
| 电池 | 5000mAh | 5100mAh |
| 有线快充 | 66W | 100W |
| 无线充电 | 不支持 | 50W |
| 后置主摄 | 5000 万像素 | 5000 万像素 + 1200 万超广角 |
| 防水等级 | IP53 | IP68 |

## 选择建议

- 日常使用、预算有限：选 X1
- 追求性能、拍照、户外使用：选 X1 Pro

X1 Pro 更适合经常户外使用的用户，IP68 防水等级能应对雨水和灰尘环境。
