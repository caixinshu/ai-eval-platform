# 账号安全

## 两步验证

开启两步验证可大幅提升账号安全性：
1. 进入「设置」-「账户安全」
2. 选择「两步验证」
3. 绑定手机或验证器 App
4. 登录时需输入动态验证码

## 账号被盗

若发现账号被盗，请立即：
1. 通过「忘记密码」重置密码
2. 检查并解绑陌生设备
3. 联系客服冻结账号
4. 修改绑定的手机号和邮箱

## 账号冻结

账号被冻结的常见原因：
- 多次输错密码
- 异常登录行为
- 违规操作

解冻方式：联系客服，完成身份验证后即可解冻。

## 账号注销

注销账号步骤：
1. 进入「设置」-「账户安全」
2. 选择「注销账号」
3. 阅读注销须知并确认
4. 验证身份后提交

注销后账号数据将无法恢复，请谨慎操作。

## 设备管理

可在「账户安全」-「设备管理」中查看所有登录设备，及时移除陌生设备。
